۱ · قرارداد، در خود فایل نوشته شده (خط ۵–۷)

The point of the whole study: the PAYLOAD is identical in every arm (the same
lon/lat for the same chip). Only the ENTRY POINT changes. Anything that differs
between arms is therefore attributable to routing, not to information.

این سه خط کل طرح آزمایش است. اگر فقط یک چیز از کد بگویی، این باشد.

۲ · کدگذار مکان (خط ۳۰–۵۴) — بی‌پارامتر و مشترک

چه می‌کند: دو عدد (lon, lat) را به یک بردار ۱۹۲ بعدی تبدیل می‌کند. ۲ زاویه × ۲ تابع (sin/cos) × ۴۸ فرکانس = ۱۹۲.

چرا فرکانس‌های مختلف: freqs یک دنبالهٔ هندسی از ۱ تا ۱۰⁻⁴ است. فرکانس پایین می‌گوید «شمال یا جنوب اروپا»، فرکانس بالا می‌گوید «این دره یا آن دره». مثل ساعتی که عقربهٔ ساعت و دقیقه و ثانیه دارد — هر کدام یک مقیاس.

چرا بی‌پارامتر؟ خط ۳۴–۳۷ خودش جواب داده: اگر کدگذار یادگیرنده بود، بازوها در «چقدر خوب می‌توانند مختصات را بخوانند» فرق می‌کردند، نه فقط در «کجا واردش می‌کنند» — و مقایسه دیگر مسیریابی را جدا نمی‌کرد.
⚠️ ضعفی که باید خودت بگویی: آن * 10.0 در خط ۴۸ یک عدد جادویی بدون توجیه است. جایی مستند نشده چرا ۱۰. چون در همهٔ بازوها یکسان است، مقایسه را خراب نمی‌کند — ولی سطح مطلق را ممکن است جابه‌جا کند. ابلیشن نشده.

۳ · بلوک ترنسفورمر (خط ۶۶–۷۵) — و بزرگراه باقیمانده

67  if mod is None:                                  # مسیر بدون تزریق
68      a = self.n1(x)
69      x = x + self.attn(a, a, a)[0]
70      return x + self.mlp(self.n2(x))
71  s1, g1, s2, g2 = mod                             # مسیر adaLN
72  a = self.n1(x) * (1 + g1.unsqueeze(1)) + s1.unsqueeze(1)
73  x = x + self.attn(a, a, a)[0]
74  b = self.n2(x) * (1 + g2.unsqueeze(1)) + s2.unsqueeze(1)
75  return x + self.mlp(b)

آن x = x + یک نوار نقاله است که از ورودی تا خروجی بی‌وقفه می‌رود. هر چیزی که رویش بنشیند تا انتها زنده می‌ماند. اصطلاح رایجش residual stream است.

مقایسهٔ خط ۶۹ با خط ۷۲–۷۳ — کل توضیح مکانیکی اینجاست.

در مسیر adaLN، s1 و g1 فقط ورودی attention را تغییر شکل می‌دهند. هیچ‌جا x = x + loc نداریم. یعنی مکان هرگز کپی مستقیمی روی نوار نمی‌گذارد — فقط شکل چیزی که attention تولید می‌کند را عوض می‌کند.

اشتقاق تعداد پارامترها — این را باید بتوانی روی کاغذ بکشی:

add    :  یک اسکالر                                        =         1
token  :  Linear(192->192)  = 192*192 + 192                =    37,056
gate   :  Linear(192->48)   = 192*48 + 48   =  9,264
          Linear(48->1)     =  48*1  +  1   =     49        =     9,313
adaln  :  Linear(192->768)  = 192*768 + 768 = 148,224
          x 6 block                                        =   889,344

چرا 4*dim؟ دو LayerNorm در هر بلوک، هرکدام یک shift و یک scale: s1, g1, s2, g2. خط ۱۴۷ همان chunk(4) بازش می‌کند.

دو مقداردهی اولیهٔ هوشمند:
خط ۱۰۹ (adaln) — وزن صفر یعنی x·(1+0)+0 = x، پس در گام صفر دقیقاً برابر none است. از نقطهٔ بدتر شروع نمی‌کند.
خط ۱۱۶–۱۱۷ (gate) — وزن صفر و بایاس 0.1 یعنی g = 0.1 ثابت، که دقیقاً همان add است. پس هر اختلافی از یادگیریِ گیت می‌آید، نه از نقطهٔ شروع متفاوت.

۵ · forward (خط ۱۱۹–۱۵۲) — جایی که تزریق اتفاق می‌افتد

121  x = self.stem(img).flatten(2).transpose(1, 2)      # (B, 64, 192)
122  x = torch.cat([self.cls.expand(B,-1,-1), x], dim=1)# (B, 65, 192)
123  x = x + self.pos

135  elif self.arm == "gate":

141      x = x + g.unsqueeze(1) * loc.unsqueeze(1)
142  elif self.arm == "token":
143      x = torch.cat([x, self.loc_proj(loc).unsqueeze(1)], dim=1)   # (B, 66, 192)
145  for i, blk in enumerate(self.blocks):
146      if self.arm in ("adaln", "shuffle"):
147          x = blk(x, self.to_mod[i](loc).chunk(4, dim=1))
148      else:

151  out = self.head(self.norm(x)[:, 0])                # [:, 0] = فقط CLS
خط ۱۳۹ — چرا گیت x[:, 1:] می‌خواند و نه loc. در آن نقطه loc هنوز به x اضافه نشده (خط ۱۴۱ اضافه‌اش می‌کند). پس گیت کور به مکان است. اگر نبود، بازوی gate دو مسیر برای مکان داشت و مقایسه با add دیگر «دروازهٔ نمونه‌ای» را جدا نمی‌کرد. آزمون T5 همین را با 0.000e+00 تأیید می‌کند.
خط ۱۵۱ — [:, 0] کلید کل نتیجه است. فقط CLS به طبقه‌بند می‌رسد. add در خط ۱۳۴ مکان را به همهٔ توکن‌ها اضافه می‌کند — از جمله CLS. یعنی فاصلهٔ مکان تا تصمیم: صفر لایه. در adaln این مسیر مستقیم وجود ندارد.

ب · 23_test_arms.py — چرا به اعدادت می‌شود اعتماد کرد

سربرگ فایل دلیلش را نوشته: گران‌ترین باگ فاز آتش‌سوزی یک تست هم‌ارزی بود که فقط برابری را می‌سنجید و در حالی که ماژول تزریق قطع بود، پاس شد.

آزمونچه می‌سنجدنوع
T1none مختصات را کاملاً نادیده می‌گیردباید برابر باشد
T2هر بازوی تزریقی با عوض شدن مختصات خروجی‌اش عوض شودباید فرق کند
T3adaln در مقداردهی اولیه = noneباید برابر باشد
T4هر پارامتر تزریق گرادیان بگیرد و در بهینه‌ساز باشدباید ناصفر باشد
T5گیت به تصویر وابسته باشد و به مختصات نباشدباید برابر باشد

دو ریزه‌کاری که نشان می‌دهد کسی واقعاً فکر کرده:

55  # adaln/shuffle are zero-initialised, so randomise the modulator first -
56  # otherwise this test would pass trivially by being identity.

بدون این، T2 برای adaLN بی‌معنا بود: ماژول صفر است، خروجی عوض نمی‌شود، تست می‌گفت «فرق نکرد» و اشتباهاً FAIL می‌داد — یا بدتر، اگر برعکس نوشته بودی، PASS.

83  # adaLN-zero has exactly zero gradient at step 1 by construction
84  # (dL/dloc-encoder = W^T g = 0 while W is zero). Measured: 0.000e+00 at
85  # step 1, 1.38e-01 at step 2. So we look at the LAST step.
این یکی از بهترین چیزهای پروژه است. یک صفر دیدند، و به‌جای اینکه باگ اعلامش کنند، حساب کردند آن صفر باید چه باشد. با وزن صفر، گرادیانِ انکودر شرط ریاضاً صفر است. اگر شرط تست «همهٔ گام‌ها» بود، یک رفتار درست باگ شمرده می‌شد.

درس: پیش از اینکه یک صفر را خرابی بدانی، حساب کن آن صفر باید چه باشد.

۱ · آمار نرمال‌سازی فقط از آموزش (خط ~۴۵)

mu = img[tr].mean(axis=(0,2,3), keepdims=True)
sd = img[tr].std(axis=(0,2,3), keepdims=True) + 1e-6

img[tr] — فقط تکهٔ آموزش. اگر میانگین را از کل داده می‌گرفتی، اطلاعات مجموعهٔ ارزیابی وارد آموزش می‌شد. یک نشت کوچک ولی واقعی.

۲ · شافل با صفر نقطهٔ ثابت (خط ۵۵–۹۰)

perm = torch.randperm(len(c), generator=g)
for _ in range(64):
    fixed = (perm == idx).nonzero().flatten()
    if len(fixed) == 0: break
    if len(fixed) == 1:  perm[[f, j]] = perm[[j, f]]
    else:                perm[fixed] = perm[torch.roll(fixed, 1)]
if (perm == idx).sum(): raise RuntimeError("shuffle left N fixed points")
if len(torch.unique(perm)) != len(c): raise RuntimeError("not a bijection")
باگ واقعی، اندازه‌گیری‌شده ۱ اوت، seed 3: نسخهٔ قبلی یک بار torch.roll می‌زد و امیدوار بود. چرخاندن یک جایگشت هیچ تضمینی برای حذف نقاط ثابت نمی‌دهد. assertion گرفتش — وگرنه دو نمونه مختصات درست خودشان را نگه می‌داشتند و کنترل بی‌صدا آلوده می‌شد.

«نقطهٔ ثابت» = نمونه‌ای که بعد از شافل، مختصات خودش را گرفته. در جایگشتی که هیچ نقطهٔ ثابتی ندارد به آن derangement می‌گویند.

ث · امتحان

۱. خط ۱۳۴ (add) مکان را به همهٔ ۶۵ توکن اضافه می‌کند. اگر فقط به CLS اضافه می‌کرد، چه فرقی می‌کرد؟ بهتر می‌شد یا بدتر — و چرا؟
۲. در T2، برای adaln اول وزن‌های مدولاتور را تصادفی می‌کنند. اگر این کار را نمی‌کردند، تست چه می‌گفت و چرا آن جواب بی‌معنا بود؟
۳. gate در گام صفر دقیقاً برابر add است. چرا این طراحی عمدی است و چه چیزی را ممکن می‌کند؟
۴. نرمال‌سازی از img[tr] حساب می‌شود، نه از کل داده. اگر از کل داده حساب می‌شد، دقیقاً چه نوع نشتی رخ می‌داد؟ (به بلوک ۲ وصلش کن.)
۵ — سخت. token دنباله را از ۶۵ به ۶۶ توکن می‌برد، پس کمی محاسبهٔ بیشتری هم می‌گیرد. یک داور می‌گوید «پس مقایسه‌ات ناعادلانه است». جوابت چیست؟ (راهنمایی: ۱.۵٪ بیشتر محاسبه در برابر چه اختلافی در نتیجه؟)
